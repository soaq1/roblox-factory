# 베타판

- 날짜: 2026-10-05
- 상태: 코드 작성 완료, **스튜디오에서 실행해 본 적 없음**
- 앞선 판: [첫 실행판 "철 한 줄"](2026-10-05-first-playable.md)

## 무엇인가

설계 문서의 게임을 처음부터 끝까지 한 번 이어 붙인 판이다. 곡괭이 하나와 10,000코인으로 빈 섬에서 시작해, 허브에서 캐고 사고팔고, 손으로 만들다가 공장을 짓고, 전기를 깔고, 다른 사람과 거래하는 데까지 길이 나 있다.

숫자(가격, 확률, 속도, 전력)는 거의 전부 임시 값이다. 이 판의 목적은 흐름이 이어지는지 보는 것이지 균형이 아니다.

## 바로 해 보기

`game/build/roblox-factory.rbxlx`를 로블록스 스튜디오에서 열고 F5. 도구 설치는 필요 없다.

두 사람이 필요한 것(거래, 자판기, 섬 구경)은 스튜디오의 "테스트 → 로컬 서버 → 플레이어 2명"으로 본다.

## 조작

마인크래프트처럼 **아래 아이템 바에서 고른 것이 손에 들리고, 좌클릭이 그것을 쓴다.**

| 입력 | 동작 |
|---|---|
| 1~9, 0 | 아이템 바의 열 칸 고르기 |
| 좌클릭 | 손에 든 것 쓰기. 블록·기계는 놓기, 도구(곡괭이·도끼·삽·괭이)는 부수기와 캐기, 검은 때리기. **그 밖의 아이템을 들었으면 아무 일도 없음** |
| 좌클릭 누르고 있기 | 도구로 계속 치기 |
| Q | 손에 든 아이템 하나 떨구기. 누르고 있으면 계속. 조준한 칸에, 조준한 곳이 없으면 발 앞에 떨어짐 |
| R | 손에 든 벨트나 기계의 방향 돌리기 |
| F | 떨어진 아이템 줍기, 작업대(조합 화면이 열림)·포탈·상인·기계·상자와 상호작용 |
| E | 인벤토리. 생존에서는 가방, 크리에이티브에서는 전체 목록 |
| Shift | 달리기 |
| 우클릭 드래그 | 화면 돌리기 |
| C / T / V | 조합 / 거래 / 다른 섬 구경 |

- **마지막 도구는 떨구거나 거래에 올릴 수 없고**, 도구가 하나도 없는 채로 접속하면 나무 곡괭이를 다시 받는다. 도구 없이는 나무도 못 캐서 영영 막히기 때문이다.
- **도구를 손에 들지 않으면 아무것도 부술 수 없다.** 캐는 속도는 가방에서 제일 좋은 도구가 아니라 지금 손에 든 도구로 정해진다. 맞지 않는 도구(곡괭이로 나무)는 되긴 하지만 느리다.
- 물건은 자기 섬에서만 떨굴 수 있다(다른 곳에 두면 아무도 못 줍기 때문).
- 생존 모드에서 아이템 바는 가방을 따라간다. 새로 얻은 것은 빈 칸에 올라가고, 다 쓴 것은 칸에서 빠진다. 가방(E)에서 눌러 원하는 칸에 넣을 수도 있다.
- 손에 든 것은 화면에 보인다. 가까이 당긴 시점(1인칭)에서는 화면 오른쪽 아래에, 멀리서는 캐릭터의 오른손에. 쓸 때마다 휘두른다. 이 모습은 자기 화면에만 보인다.

채팅 명령은 맨 아래에 있다.

## 처음 접속해서 할 수 있는 일

1. **섬**: 흙과 돌 땅, 나무 두 그루. 가방에 나무 곡괭이, 지갑에 10,000코인.
2. **나무와 땅 캐기**: 누르고 있으면 여러 번 쳐서 부서지고 가방에 들어온다. 도구가 좋을수록 적게 친다.
3. **조합(C)**: 지금 만들 수 있는 것과 못 만드는 이유가 보인다. 판자 → 기본 작업대 → 다른 작업대.
4. **포탈**: 시작 지점 북쪽의 "허브로". 허브에는 "내 섬으로"와 "몬스터 섬" 포탈이 있다.
5. **허브의 상인**: 농부(씨앗과 묘목을 팔고 작물을 삼), 광부(광물, 주괴, 작은 부품을 삼), 요리사(음식을 삼), 건축가(꾸미기 블록을 팖).
6. **광산**: 바위를 캐면 가방에 들어오고 잠시 뒤 다시 생긴다. 낮은 확률로 광맥 핵이 나온다.
7. **몬스터 섬**: 슬라임을 잡으면 낮은 확률로 몬스터 부품이 나온다.
8. **손 작업**: 손 화덕에서 광석을 녹인다. 연료가 필요하다.
9. **추출기**: 빈 추출기(돌, 철 주괴, 판자, 몬스터 부품)에 광맥 핵을 조합하면 그 광물의 추출기가 된다.
10. **공장**: 벨트로 기계를 잇는다.
11. **전기**: 발전기와 전신주를 깔면 기계가 빨라지고 연료를 덜 쓴다. 전기가 있어야만 도는 기계도 있다.
12. **거래**: 거래 창, 자판기, 다른 섬 구경.
13. **큰 목표**: 핵 제련소(광맥 핵을 만듦), 무한 동력로.

## 들어 있는 것

### 섬과 짓기

- 블록 34종. 섬 크기에 제한 없음.
- 기계는 자기 키만큼 위 칸도 차지한다. 한 칸이 3스터드이고 기계 대부분이 4~6스터드라 **두 층을 차지하는 기계가 많다.**
- 2×1, 2×2, 3×3칸 기계는 그만큼 칸을 차지한다. 조준한 칸이 기계의 뒤쪽 왼쪽 모서리가 된다.
- 기계의 겉모습은 카탈로그 모델을 로블록스 기본 도형으로 자동 변환한 것이다.

### 기계

카탈로그의 81종 가운데 73종이 동작한다. 모양만 있는 것은 포장기, 분해기, 도색기, 빈 추출기(조합 재료)이고, 판매기는 쓰지 않는다.

| 종류 | 기계 | 동작 |
|---|---|---|
| 벨트 | 직선, 코너(좌·우), 열린 벨트, 경사 벨트, 낙하 통로 | 닿은 것을 물리로 실어 나름 |
| 내보내기 | 추출기(철·석탄·구리), 물 펌프, 펌프잭 | 2초마다 하나 |
| 가공 22종 | 제련로, 분쇄기, 세척기, 체, 프레스, 선반, 신선기, 주조기, 제재기, 가마, 고로, 합금로, 혼합기, 제분기, 오븐, 착유기, 정유탑, 직조기, 석재 절단기, 보석 세공기, 압축기, 핵 제련소 | `docs/recipes.md`의 가공 표 그대로 |
| 조립 | 조립기, 회로 제작기, 제조 공장 | 주인이 F로 무엇을 만들지 고름. 전기 필요 |
| 넘기기 | 분배기, 합류기, 깔때기, 자석 분리기, 분류기 | 분류기는 주인이 고른 아이템만 둘째 출구로 |
| 물리 장치 | 수직 승강기, 발사기, 밀대, 송풍기 | 전기 필요. 발사기는 F로 거리를 바꿈 |
| 농사 | 벌목기, 수확기, 파종기, 물뿌리개 | 주변 나무와 작물을 돌봄 |
| 신호 | 스위치, 감지기, 타이머, 계수기, 논리 회로함, 여닫이 문, 신호등 | 아래 "신호" 참고 |
| 전기 | 석탄 발전기, 소각로, 풍력 터빈, 태양광 패널, 축전지, 전신주, 무한 동력로 | 아래 "전기" 참고 |
| 보관과 거래 | 보관함, 상자, 자판기 | |
| 작업대 | 작업대 일곱 개, 통합 작업대, 손 화덕, 모닥불 | 가까이 있으면 조합할 수 있음 |

**입구가 받는 범위**: 입구는 바짝 닿은 것만 받는다. 벨트 끝이 입구를 향해 있어야 하고, 입구 앞을 옆으로 지나가는 벨트의 물건은 건드리지 않는다.

**기계끼리 붙였을 때**: 출구 바로 앞에 다른 기계의 입구가 있으면 벨트 없이 넘겨준다.

**막혔을 때**: 출구 앞에 물건이 있으면 기다리고, 안에 쌓이면 작업을 멈춘다. 그래서 뒤가 막히면 앞까지 밀린다.

### 전기

- **만들기**: 석탄 발전기(연료를 태워 일정하게, 쓰는 만큼만 태움), 풍력(들쭉날쭉), 태양광(해를 따라감), 소각로(들어온 것을 전부 태워 조금), 무한 동력로(섬 전체에 무제한).
- **나르기**: 전신주끼리 10칸 안이면 전선으로 이어진다. 전신주에서 5칸 안의 기계가 전기를 받는다. 발전기에서 2.5칸 안은 전신주 없이 받는다.
- **모으기**: 축전지.
- **쓰기**: 전기가 꼭 필요한 기계는 없으면 "전기 없음"이라고 뜨고 멈춘다. 필요 없는 가공 기계도 전기가 들어오면 1.5배 빨라지고 연료를 절반만 쓴다.
- 하루는 실제 20분이다.

### 신호

1. **보내는 것**: 스위치(F로 켜고 끔), 감지기(위에 물건이 있는 동안), 타이머(주기의 앞 절반), 계수기(정한 수만큼 지나갈 때마다 잠깐).
2. **받는 것**은 맞닿은 여섯 칸의 보내는 것을 읽는다. 논리 회로함은 그리고 / 또는 / 아님, 여닫이 문은 켜지면 열림, 신호등은 켜지면 빛남.
3. 스위치, 타이머, 논리 회로함 옆의 보통 기계는 그중 하나라도 켜져 있어야 돈다.

### 농사

- 묘목은 잔디나 흙 위에 심고 45초 뒤 나무가 된다. 밀 씨앗은 경작지 위에 심고 60초에 걸쳐 자란다.
- 물뿌리개 옆에서는 두 배로 빨리 자란다.
- 벌목기는 주변 나무를 베고, 다 벤 자리에 묘목을 다시 심는다.

### 가방, 조합, 작업대

- 가방은 아이템, 기계, 블록을 모두 담는다.
- 블록을 부수면: 통나무와 돌처럼 아이템이기도 한 블록은 그 아이템으로, 흙은 흙덩이로, 나뭇잎은 10% 확률로 묘목이, 나머지는 블록 그대로.
- 조합 141종. 가방 조합은 어디서나, 나머지는 해당 작업대에서 15스터드 안.
- 작업대는 1~3단계. 단계는 섬에 붙어서 작업대를 옮겨도 남는다.
- 손 작업은 해당 자리 가까이에서, 도구(망치, 양동이)가 가방에 있어야 하고, 불을 쓰는 작업은 가방의 연료를 약한 것부터 태운다.

### 돈과 거래

- 게임이 파는 것은 **씨앗, 묘목, 꾸미기 블록뿐**이다. 건축가는 재료로 쓸 수 없는 블록만 판다(돈으로 재료를 사는 길을 막기 위해).
- 상인은 작물, 음식, 광물, 주괴, 작은 부품을 사 준다. 상인 가까이에 있어야 한다.
- **섬에 놓는 판매기는 없다.** 파는 길은 상인에게 가져가기, 플레이어 거래, 자판기뿐이다.
- 거래 창: 누가 올린 것을 바꾸면 양쪽 준비가 풀리고 화면에 노랗게 표시된다. 교환 직전에 양쪽이 올린 것을 아직 갖고 있는지 다시 확인한다.
- 자판기: 주인이 물건, 값, 판매/구매를 정하고 가방에서 채운다. 방문자가 사거나 판다. 구매 모드에는 몇 개까지 살지 한도가 있다.
- 방문자는 남의 섬을 고치거나 바닥의 물건을 주울 수 없다.

### 두 가지 모드

기본은 생존이다. `/mode creative`를 치면 무엇이든 무한히 놓을 수 있고 한 번에 부서진다. 이 전환은 시험용이며 출시 전에 없앤다.

## 아직 없는 것

- **면화와 기름 작물**: 가격과 레시피는 있는데 심을 방법이 없다. 그래서 천이 필요한 제분기와 체도 생존에서는 만들 수 없다.
- **낚시**, 경험치와 레벨, 도감.
- 포장기, 분해기, 도색기의 동작.
- 손 작업에 걸리는 시간(지금은 즉시).
- 섬 공개 여부 설정(지금은 서버의 모든 섬에 갈 수 있다).
- 거래나 자판기 도중 서버가 꺼졌을 때의 처리. 두 사람의 저장이 따로 이뤄져 한쪽만 저장될 수 있다.
- 균형 전부.

## 구조

```
art/factorykit.py -- gamedata   →  game/tools/modeldata.json
art/blocks.py                   →  art/catalog/blocks.json
data/recipes.py                 →  data/recipes.json
                 game/tools/gen_data.py
                          ↓
game/src/shared/Defs.luau, Recipes.luau, ModelPalette.luau, Models/*.luau   (자동 생성)
```

- `src/shared/*Logic.luau`: 로블록스 기능 없이 도는 규칙. 전부 시험이 있다.
- `src/server/machines/`: 기계 동작 종류마다 파일 하나.
- `src/server/*Service.luau`: 섬, 놓기와 부수기, 아이템, 조합, 거래, 상점, 방문, 허브, 광산, 몬스터, 전기, 저장.
- `src/server/MachineActs.luau`: 놓인 기계에 무언가를 하는 요청(설정, 자판기 구매)이 지나는 통로.
- `src/client/`: `UIKit`과 `Screens` 위에 화면마다 파일 하나.

## 확인한 것과 못 한 것

**확인함**

- 자동 시험 178개. 거래와 자판기에서 물건이나 코인이 생기거나 사라지지 않는지를 무작위로 수백 번 돌려 보는 것 포함.
- 문법, 타입, 흔한 실수 검사와 게임 파일 빌드.
- 기계 84종을 네 방향으로 놓았을 때 입구와 출구가 제자리에 오는지(계산으로, 832건).
- 다른 Claude의 코드 검토 두 차례.
  - 첫째(기계와 벨트): 찾은 문제 다섯 가지를 고쳤다.
  - 둘째(다섯 갈래를 합친 뒤의 이음매): 서버와 화면이 시작을 못 할 오류는 찾지 못했다. 생존 플레이를 막는 문제 둘(경작지를 만들 수 없던 것, 마지막 도구를 잃으면 다시는 아무것도 못 하던 것)과 작은 것 일곱을 고쳤다.

**확인 못 함**: 스튜디오에서의 실행 전부. 특히

1. 물리. 아이템이 벨트를 매끄럽게 타는지, 코너에서 걸리지 않는지, 경사 벨트 끝에서 넘어가는지, 발사기가 겨냥한 곳에 떨어지는지.
2. 화면이 작은 창에서 잘리지 않는지, 그림이 제대로 나오는지.
3. 포탈로 옮겨 다닐 때 문제가 없는지.
4. 슬라임이 캐릭터와 부딪힐 때의 움직임.
5. 기계가 많을 때의 속도.

## 스튜디오에서 해 볼 순서

1. 실행해서 섬에 서 있는지, 화면 아래 단축 칸과 오른쪽 위 코인이 보이는지. 출력 창의 빨간 글씨는 그대로 전달.
2. 1번 칸의 곡괭이를 든 채 나무를 누르고 있어서 캐기. 손에 든 곡괭이가 보이고 휘둘러지는지, 통나무가 아이템 바 빈 칸에 올라오는지.
3. 조합(C)에서 판자 → 기본 작업대. 놓고 그 옆에서 다른 것이 만들어지는지.
4. 포탈로 허브에 가서 상인(F), 광산, 몬스터 섬.
5. `/mode creative`로 바꾸고 E 목록에서 골라 공장 짓기(부술 때는 아이템 탭에서 아무 곡괭이나 골라 듦): 철 추출기 → 벨트 → 제련로 → 벨트 → 보관함, 석탄 추출기를 코너 벨트로 합류.
6. 석탄 발전기를 제련로 옆에 놓고 석탄을 넣어 "빨라지는지" 보기. 전신주로 늘려 보기.
7. 조립기를 놓고 F로 만들 것을 고르기.
8. 플레이어 2명으로 거래(T), 자판기, 섬 구경(V).

## 채팅 명령

물건 이름은 영어 이름(`ingot_fe`, `block:planks`)이나 띄어쓰기를 뺀 한글 이름(`철주괴`)으로 쓴다.

| 명령 | 동작 |
|---|---|
| `/mode survival` · `/mode creative` | 모드 전환 |
| `/give 철주괴 50` | 가방에 넣기. 크리에이티브에서만 |
| `/speed 5` | 추출기와 식물을 5배속으로 |
| `/wipe` | 굴러다니는 아이템 모두 지우기 |
| `/can` · `/craft 벨트 3` · `/hand 철주괴 4` · `/upgrade 기본작업대` | 조합 화면과 같은 일 |
| `/trade 이름` · `/offer 철주괴 10` · `/coins 500` · `/ready` · `/unready` · `/cancel` | 거래 화면과 같은 일 |
