# 로블록스로 가져갈 모델

카탈로그의 모델을 로블록스 스튜디오에서 불러올 수 있게 뽑아 둔 파일입니다. **스튜디오에서 실제로 불러와 본 적은 아직 없습니다.** 아래의 "확인할 것"을 먼저 봐 주세요.

## 들어 있는 것

| 위치 | 내용 |
|---|---|
| `machines/*.fbx` | 기계와 장치 77종. 파일 하나에 모델 하나 |
| `items/*.fbx` | 아이템 108종 |
| `textures/*.png` | 블록 텍스처 38장. 32픽셀 원본을 512픽셀로 키운 것 |
| `models.json` | 모델마다 크기, 중심 위치, 삼각형 수 |

## 만든 방식

- **색은 꼭짓점 색으로 넣었습니다.** 로블록스의 메시는 기본적으로 한 덩어리에 한 색이라, 색마다 재질을 나누면 기계 하나가 부품 열 개로 쪼개집니다. 꼭짓점마다 색을 넣어 두면 한 덩어리로 유지됩니다.
- **한 칸이 3스터드가 되게 키웠습니다.** 게임의 격자 한 칸과 같습니다.
- 빛나는 부분(제련로의 불, 광맥 핵)은 빛나는 성질 없이 색만 들어갑니다. 빛나게 하려면 그 부분을 따로 떼어 네온 재질을 줘야 합니다.
- 블록 텍스처는 키워서 뽑았습니다. 로블록스가 작은 그림을 흐리게 보여 주기 때문입니다.

## 다시 뽑기

```
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/factorykit.py -- export
/Applications/Blender.app/Contents/MacOS/Blender --background --python art/blocks.py
```

## 확인할 것

스튜디오에서 기계 하나(예: `machines/smelter.fbx`)를 불러와서 아래를 봅니다. 스튜디오의 파일 메뉴나 홈 탭에 있는 "3D 가져오기"로 불러옵니다.

1. **크기가 맞는가.** 제련로는 가로와 세로가 3스터드, 높이가 5.8스터드쯤이어야 합니다. 100배 크거나 작게 들어오면 가져오기 창의 단위 설정을 바꾸거나, 내보낼 때의 배율을 고쳐야 합니다.
2. **색이 들어오는가.** 회색 몸체, 노란 입구, 청록 출구가 보여야 합니다. 온통 한 색이면 가져오기 창에 꼭짓점 색을 무시하는 설정이 켜져 있는지 봅니다.
3. **한 덩어리로 들어오는가.** 탐색기에서 부품이 하나여야 합니다.
4. **방향이 맞는가.** 청록 출구가 X축 양의 방향을 봐야 합니다.

결과에 따라 내보내는 방식을 고칩니다. 꼭짓점 색이 안 통하면 작은 색상표 그림 하나에 모든 색을 담는 방식으로 바꿀 수 있습니다.

## 알아 둘 점

- 기계는 대부분 한 칸보다 높습니다(제련로는 두 칸 가까이). 기계 위에 바로 블록을 쌓으면 겹칩니다.
- 로블록스는 모델을 가져올 때 원점을 덩어리의 한가운데로 옮깁니다. 바닥에 맞춰 놓으려면 `models.json`의 `center` 값을 씁니다.
- 지금 게임 코드는 이 모델을 쓰지 않고 기본 도형으로 만든 임시 모양을 씁니다.
